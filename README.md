# Weather-Apk
Weather Apk Using HTML5, CSS, Javascript &amp; API

🌤️ Excited to share my latest project: A Real-Time Weather Web App! 🚀

I just wrapped up building a clean, responsive Weather App using core web technologies and external API integration. It provides instant real-time weather metrics with a slick, user-friendly UI.


🛠️ Tech Stack & Features:

HTML5: Structured semantic markup for clean UI design.

CSS3: Designed with a modern purple gradient, custom rounded cards, and flexible layouts.

JavaScript (ES6+): Utilized fetch() and async/await to handle asynchronous API calls dynamically.

Weather API: Integrated a live weather API to retrieve accurate real-time metrics including temperature, location name, humidity percentage, and wind speed.


Key Features:

🔍 Instant city-based location search

🌡️ Real-time temperature updates

💧 Live humidity & wind speed tracking

📱 Mobile-friendly, responsive card interface


Building this was a great refresher on handling asynchronous JavaScript, managing API keys securely, and translating UI designs into clean code.
